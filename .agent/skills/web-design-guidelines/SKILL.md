# Web Design Guidelines

## Aesthetics & Premium Feel
- **Visual Hierarchy**: Use spacing, typography size, and color weight to guide the user's eye.
- **Whitespace**: Don't fear whitespace. It adds elegance and readability.
- **Micro-interactions**: feedback for user actions (hover, click, focus) to make the UI feel "alive".

## Responsive Design
- **Mobile First**: Design for smaller screens first, then scale up.
- **Fluid Layouts**: Use percentages or `fr` units. Avoid fixed pixel widths for containers.
- **Breakpoints**: Use standard breakpoints compatible with Ant Design Grid system.

## Accessibility (a11y)
- **Contrast**: Ensure sufficient color contrast.
- **Keyboard Navigation**: All interactive elements must be focusable and usable via keyboard.
- **Semantic HTML**: Use `<main>`, `<nav>`, `<header>`, `<article>` appropriately.

## Liferay/AntD Specifics
- **Theming**: Customize Ant Design tokens rather than overriding CSS definitions manually where possible.
- **Consistency**: Stick to the defined color palette and typography scale.
