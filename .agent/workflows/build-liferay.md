description: Build and sync React app to Liferay, then compress the fragment with deployment descriptor.
---

1. Build and sync the React application to the Liferay fragment structure.
// turbo
2. Run the build:liferay command in the root directory
3. Navigate to the liferay-test directory
4. Run the compress command
5. When prompted "Add deployment descriptor?", enter "Y".
6. When prompted "Deployment descriptor company Web ID?", enter "liferay.com".
7. When prompted "Deployment descriptor group key?", enter "Guest".
