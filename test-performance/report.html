Khuyến nghị

  • Cao
    Bật cache cho trang public /web/guest
    Trang này không yêu cầu đăng nhập — bật Liferay Layout Cache hoặc đặt Nginx proxy_cache phía trước để tránh render lại mỗi request. Đây là tối ưu hiệu quả cao nhất với ít rủi ro nhất.
  • Cao
    Tối ưu database & connection pool
    TTFB chiếm ~84% response time — cần kiểm tra slow query log và HikariCP maximumPoolSize. Khi pool bị đầy ở tải cao (>100 VU), các request xếp hàng chờ connection khiến TTFB tăng đột biến.
  • Trung bình
    Kiểm tra JVM heap & Tomcat thread pool
    Xem xét tăng maxThreads trong Tomcat connector và kiểm tra GC pause log. Với 150 VU đồng thời, JVM có thể bị GC pause hoặc thread pool saturated làm tăng TTFB.
  • Trung bình
    Xác định ngưỡng VU chính xác
    Chạy lại với ramping-vus theo bước nhỏ (50 → 70 → 90 → 110 → 130 VU) để tìm điểm chính xác mà p(95) bắt đầu vượt 2s. Hiện tại server ổn định ở khoảng 100–120 VU đồng thời.

Kết luận

Server chưa đạt SLA p(95) < 2 000ms khi tải vượt ~120 VU đồng thời. Không có lỗi HTTP thực sự — toàn bộ vấn đề đến từ thời gian xử lý chậm ở tầng ứng dụng. Ưu tiên ngay là bật cache trang public và tối ưu database connection pool để đưa TTFB xuống dưới 1 500ms, từ đó p(95) sẽ đạt ngưỡng 2s.
